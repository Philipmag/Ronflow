# Ronflow Extension - Installation & Testing Guide

## Quick Start (5 minutes)

### Step 1: Build the Extension

```bash
cd ronflow/extension
npm install
npm run build
```

### Step 2: Load in Chrome

1. Open Chrome and go to `chrome://extensions/`
2. Enable **"Developer mode"** (toggle in top-right corner)
3. Click **"Load unpacked"** button
4. Select the folder: `ronflow/extension/dist`
5. Extension icon should appear in your toolbar

### Step 3: Start the Ronflow Backend

In a separate terminal:

```bash
cd ronflow
npm install
npm run dev
```

Server will start at `http://localhost:3000`

### Step 4: Test Recording

1. Click the Ronflow extension icon in Chrome toolbar
2. Verify server shows green checkmark (✓)
3. Click **"Start Recording"**
4. Navigate to any website and perform actions:
   - Click buttons
   - Fill form fields
   - Navigate between pages
5. Watch the floating toolbar count your steps
6. Click **"Stop & Process"**
7. A new tab opens with your AI-generated documentation!

## Troubleshooting

### "Server disconnected" showing in popup

**Solution:** Ensure backend is running:
```bash
cd ronflow && npm run dev
```

### Extension not capturing clicks

**Solutions:**
1. Refresh the page you're testing on
2. Check browser console for "[Ronflow]" logs
3. Ensure content script loaded (check DevTools → Console)

### No screenshot captured

**Note:** Screenshots may fail on:
- Chrome internal pages (`chrome://`)
- About pages (`about:blank`)
- Pages with restrictive CSP headers

Try testing on regular websites first (e.g., google.com, github.com).

### Build errors

```bash
# Clean and rebuild
rm -rf dist node_modules
npm install
npm run build
```
