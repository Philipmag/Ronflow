# Ronflow AI Engine

Welcome to the **Ronflow** repository - a next-generation interactive procedural documentation assistant.

## 📁 Project Structure

```
/workspace
└── ronflow/          # Main application source code
    ├── src/          # React frontend components
    ├── projects/     # SOP project data storage
    ├── server.ts     # Express backend server with Gemini AI integration
    ├── index.html    # HTML entry point
    ├── package.json  # Node.js dependencies and scripts
    ├── tsconfig.json # TypeScript configuration
    └── vite.config.ts # Vite build configuration
```

## 🚀 Quick Start

Navigate to the `ronflow` directory to get started:

```bash
cd ronflow

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run production build
npm run start
```

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 6, TailwindCSS 4, Motion
- **Backend**: Node.js, Express, TypeScript
- **AI Integration**: Google Gemini API
- **Build Tools**: esbuild, Vite
